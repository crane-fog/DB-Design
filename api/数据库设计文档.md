# 1 工业制造物料进销存管理系统数据需求
对系统数据需求，进行简要说明。

## 1.1 物料与BOM管理模块
系统的数据核心。管理物料基础信息及物料间的层级制造关系，提供物料的生产材料清单（Bill of Materials, BOM），支持递归展开、版本演进、反向追溯和成本聚合计算。

### 1.1.1 物料数据管理功能数据需求
包括物料主数据的采集、存储和生命周期管理。系统需记录的字段包括：物料编号（系统自动生成，全局唯一主码）、物料名称、物料类型（原材料、半成品、成品、辅料）、型号、计量单位、所属分类（外码关联分类表）、默认供应商（外码关联供应商表）、安全库存、创建人（外码）、版本id（外码关联版本表）、创建时间和更新时间。物料库存表记录物料编号（主码）、可用数量、已锁定数量、最后入库日期和最后出库日期。物料分类表包含分类编号（主码）、分类名称。BOM表需记录BOM编号（主码）、版本id（外码关联版本表）、父项物料（外码关联物料主表）、子项物料（外码关联物料主表）、单位用量、损耗率，每条记录表示一个物料的生产对一个材料的需求。

### 1.1.2 物料检索功能数据需求
包括跨多表的组合条件查询所需的关联数据。系统需从物料主表读取编号、名称、类型、型号、分类等基础属性，从库存数据读取可用数量、已锁定数量、最后入库日期和最后出库日期，从分类表获取层级归属，从供应商表获取供应商名称。检索条件应支持物料编号模糊匹配、名称模糊匹配、类型精确匹配、分类、供应商、库存数量范围和日期范围等。查询结果需同时展示基础信息与库存汇总，对常用检索字段应建立索引。

### 1.1.3 物料分析功能数据需求
包括BOM层级关系数据的递归读取和分析结果的持久化存储。系统需读取BOM表中的父项物料、子项物料、单位用量、损耗率、所属版本编号等，以目标产品为根节点递归展开，逐层累乘用量并按损耗率补偿。分析结果应保存为独立记录，包含目标产品、生产数量、BOM版本、分析时间、物料及净需求量（JSON）等。

### 1.1.4 循环依赖检查功能数据需求
系统在新增或修改物料信息前，需读取当前版本下所有父子物料关系，以待插入的子项物料为起点递归遍历其所有下级，若发现待插入的父项出现在下级集合中则拒绝操作。

### 1.1.5 版本控制功能数据需求
需在版本表中记录版本id（主码）、物料编号（外码关联物料主表）、版本号、生效日期（“生效”即当前物料主表中使用的版本号）、失效日期、变更原因、创建人（外码）。生产订单、成本核算等业务数据必须保存所用版本号，确保设计变更不影响历史记录。

### 1.1.6 物料清单可视化功能数据需求
系统需从BOM表递归读取指定产品指定版本的所有层级关系，每个树节点需包含物料编号、名称、型号、类型、单位用量（相对父节点）、累计用量（相对根节点，路径连乘）、层级深度、父节点编号、完整路径和是否叶子节点标识。

### 1.1.7 反向产品追溯功能数据需求
包括从BOM表自底向上的递归查询。系统以指定物料为子项，递归向上查找所有父项直至顶层成品。查询结果需包含最终产品编号、产品名称、所属BOM版本、版本状态、从目标物料到产品的完整路径、层级深度、单件用量、累计用量等。结果应区分有效版本和历史版本的依赖关系，便于判断物料变更影响范围（不被任何物料主表引用的版本即为历史版本）。

### 1.1.8 产品成本核算功能数据需求
包括BOM数据、采购价格数据。系统需读取BOM版本明细获取层级关系和损耗率，从采购价格数据（供应商报价、历史成交价或标准成本）获取叶子节点物料单价。

### 1.1.9 生产损耗补偿功能数据需求
损耗率存储在BOM表中，补偿公式为实际需求等于净需求除以（1减损耗率），结果向上取整。

## 1.2 库存管理模块
跟踪物料实时库存状态，处理锁定/释放、预警触发、缺口计算和完工入库的库存变动。

### 1.2.1 物料缺口计算功能数据需求
输入为产品编号、生产数量和BOM版本的清单，系统递归展开BOM计算中间各层级各物料总毛需求（含损耗补偿），再从物料库存表读取可用数量，从采购订单明细汇总在途数量，从物料表读取安全库存。汇总各层级的物料需求。净缺口等于毛需求减可用数量减在途数量加安全库存补充，若为负则取零。

### 1.2.2 库存预警功能数据需求
预警参数存储在物料主数据的安全库存字段中。系统比较物料的可用数量与安全库存阈值，当可用数量低于阈值时生成预警事件。预警事件表需记录预警编号（主码）、物料编号（外码）、预警类型（低库存）、触发时可用数量、预警阈值、预警时间、预警状态（待处理、已处理、已忽略）、处理人（外码关联用户表）和处理时间。同一物料已存在未处理预警时不重复生成。

### 1.2.3 物料锁定功能数据需求
锁定记录表需记录锁定编号（主码）、生产订单编号（外码）、物料编号（外码）、锁定数量、锁定状态（已锁定、已取消、已消耗）、锁定时间、释放时间和操作人（外码关联用户表）。锁定操作时增加物料表的已锁定数量并减少可用数量，订单取消时反向释放，完工入库时变更为已消耗并同步扣减已锁定数量。锁定前需校验可用数量是否充足，不足则拒绝并返回缺口。

### 1.2.4 废弃物料检测功能数据需求
系统需读取物料的最后出库日期和当前可用数量，以当前日期与最后使用日期间隔超过设定的时间且可用数量大于零为判定条件。检测结果表需记录检测编号（主码）、检测时间、物料编号（外码）、可用数量、最后出库日期、闲置天数、处理状态（待处理、已处理、已忽略）和处理人（外码）。仍被有效BOM版本引用且有活跃生产订单的物料应排除。

### 1.2.5 完工入库功能数据需求
系统需记录完工入库单，包含入库编号（主码）、生产订单编号（外码）、产品编号（外码）、BOM版本、完工数量、合格数量、成品批次号、入库时间和操作人（外码关联用户表）。执行时将对应锁定记录状态变更为已消耗，扣减原材料的已锁定数量，增加成品物料的可用数量，记录批次号以支持质量追溯。

## 1.3 采购管理模块
管理采购订单全生命周期，支持基于缺口自动生成订单草稿、多维检索和交期超期预警。

### 1.3.1 采购订单检索功能数据需求
需关联采购订单主表、明细表和供应商表进行组合查询。采购订单主表包含订单编号（主码）、订单状态（草稿、已提交、部分到货、已完成、已取消）、供应商编号（外码）、建单日期、预计交货日期、实际完成日期、采购员（外码关联用户表）和总金额。明细表记录明细编号（主码）、订单编号（外码）、物料编号（外码）、采购数量、已到货数量、单价等，每条明细对应一个订单中的一项物料。供应商表包括供应商编号（主码）、供应商名称、联系人、联系电话等。检索条件应支持供应商、物料、订单状态、建单日期范围、预计交货日期范围和采购员等，结果需展示到货进度和是否逾期。

### 1.3.2 采购订单生成功能数据需求
系统读取缺口计算结果中各物料的建议采购量，关联物料主数据获取默认供应商，按供应商生成采购订单草稿。

### 1.3.3 采购订单交期管理功能数据需求
系统需读取采购订单的预计交货日期、订单状态和到货进度，对超过预计交货日期且状态未完成的订单判定为逾期。逾期提醒表需记录提醒编号（主码）、采购订单编号（外码）、预计交货日期、逾期天数、提醒时间、处理状态（待催交、已催交、已到货）和处理备注。对于分批到货的订单，需维护多条收货记录。收货记录表包含收货编号（主码）、订单编号（外码）、物料编号（外码）、到货数量、到货日期。系统根据收货记录自动更新订单状态和到货进度。

## 1.4 生产管理模块
管理生产订单、生产线资源配置与状态，支持产能评估、故障响应和外部下单。

### 1.4.1 产能配置功能数据需求
需维护生产线类型表、生产线表、产品产能配置表和生产日历表。生产线类型表记录类型编号（主码）、类型名称。生产线表记录生产线编号（主码）、所属类型（外码）、启用日期、负责人。产品产能配置表记录配置编号（主码）、产品编号（外码关联物料表）、所需生产线类型（外码）、单件生产时间。生产日历表记录日期（主码）、生产线编号（主码）、配置编号（外码关联产能配置表）。

### 1.4.2 生产订单检索功能数据需求
生产订单主表包含订单编号（主码）、产品编号（外码）、BOM版本（外码）、计划数量、已完工数量、计划开始日期、计划完工日期、实际开始日期、实际完工日期、订单状态（待审核、待排产、生产中、已完工、已取消）。

### 1.4.3 产能估计功能数据需求
在审核生产订单时，系统需判断物料是否齐套（可用数量是否满足BOM展开需求），若不齐套则从采购订单读取预计到货时间确定最晚物料到齐日期；从产品产能配置读取所需生产线类型和工时，从生产线表和当前排产计划读取可用产能。

### 1.4.4 外部发起生产订单功能数据需求
外部订单表需记录外部订单编号（主码）、客户编号（外码关联用户表，限定外部用户类型）、产品编号（外码关联物料表）、预订数量、期望交付日期、联系人、联系电话、订单状态（待审核、已接受、已拒绝）、提交时间和审核意见。外部订单经内部审核后可转换为正式生产订单，需维护生产订单关联表以保存外部订单编号与生产订单编号的关联关系。外部用户仅能访问自身订单数据。

### 1.4.5 产能检测与平衡功能数据需求
系统需按生产线和统计周期记录计划产能、实际产能、实际工时、停机时间和生产效率。检测结果表需记录检测编号（主码）、生产线编号（外码）、周期开始时间、周期结束时间、计划产能、实际产能、差异数量、差异比例和原因分类。产能平衡操作需记录调整编号（主码）、调整前排产方案、调整后排产方案、调整人（外码关联用户表）、调整时间和受影响的生产订单编号列表（JSON）。

### 1.4.6 生产线故障反馈功能数据需求
故障记录表需记录故障编号（主码）、生产线编号（外码）、故障类型（机械故障、电气故障等）、故障描述、发生时间、恢复时间、故障状态（待维修、维修中、已恢复）、上报人和维修负责人（外码关联用户表）。

### 1.4.7 生产线状态记录功能数据需求
维护生产线状态表，包括生产线编号（主码、外码）、当前状态（空闲、运行、故障）、当前生产订单编号（外码）、当前产品编号（外码）、已完成数量、当前效率和最近更新时间。

## 1.5 质量追溯模块
通过批次号贯穿入库、出库、生产全流程，支持正向追溯（产品→原材料批次）和反向追溯（问题批次→所有受影响产品）。

### 1.5.1 质量追溯功能数据需求
需维护批次消耗关系表。以采购明细表作为原材料批次表，以生产订单表作为成品批次表。批次消耗关系表记录消耗编号（主码）、生产订单编号（外码）、原材料采购明细编号（外码）和消耗数量，形成多对多关系。正向追溯从成品批次经消耗关系查到原材料批次和供应商；反向追溯从问题批次查到所有受影响的生产订单和成品批次，支持快速冻结和召回。

## 1.6 系统管理模块
用户认证、权限控制和关键操作审计日志。

### 1.6.1 账号管理功能数据需求
用户表需记录用户编号（主码）、工号（唯一约束，用于登录）、密码哈希值、用户姓名、联系电话、邮箱、账号状态（有效、停用）、创建时间、最后登录时间和密码更新时间。账号停用后禁止登录但保留历史业务记录中的用户引用。登录行为表应记录登录时间、IP地址、登录结果和失败原因以支持安全审计。角色分配表包括用户编号（外码）和角色编号（外码）为联合主码，支持多对多关系。

### 1.6.2 用户角色功能数据需求
角色表记录角色编号（主码）、角色名称（如生产管理员、采购员、外部客户）、角色描述和状态。权限表记录权限编号（主码）、资源名称（如采购订单、生产订单）、操作类型（查看、创建、修改、删除、审核等）。角色权限关联表以角色编号（外码）和权限编号（外码）为联合主码，记录多对多关系。用户通过所属角色获得对应权限集合，系统在每次业务操作前校验当前用户角色是否具备该资源该操作的权限。

### 1.6.3 关键操作记录功能数据需求
日志表需记录日志编号（主码，自增）、操作模块（采购订单、生产订单、库存、BOM、用户管理等）、操作类型（查看、创建、修改、删除、审核等）、操作人编号（外码关联用户表）、操作时间、操作IP地址、操作前数据快照（JSON）、操作后数据快照（JSON）。日志表仅允许追加写入，不允许修改或删除，以保证审计链完整性。

# 2 概念设计
本系统共包含六个功能模块，涉及二十余个实体和五十余个联系，覆盖物料与BOM管理、库存管理、采购管理、生产管理、质量追溯和系统管理的完整业务逻辑链路。

## 2.1 总体E-R图
物料与BOM管理模块是系统的数据基础，物料实体作为全局核心被其余五个模块广泛引用。物料通过物料分类进行归类，通过物料库存记录实时库存状态（弱实体集），通过版本实体管理BOM的多版本生命周期。BOM实体作为物料与自身的多对多递归联系的关联实体，记录父子物料间的用量与损耗关系。需求分析结果实体支撑计算。供应商实体记录物料的默认供应来源。

采购管理模块围绕采购订单展开，采购订单关联供应商和采购员，采购订单明细逐项记录物料、数量和单价。收货记录跟踪到货情况，逾期提醒监控交货延迟。

库存管理模块处理库存变动与异常。预警事件在库存低于安全阈值时触发，锁定记录为生产订单预留物料，废弃物料检测结果识别长期闲置物料，完工入库单将生产成品转入库存。

生产管理模块中，生产线按类型分类，每条生产线拥有生产日历用于排产，拥有生产线状态反映实时运行情况。产品产能配置定义产品在特定线型上的生产效率。生产订单是生产执行的核心，外部订单经审核后可多对多转换为生产订单。产能检测结果和产能平衡记录支撑产能分析与调度优化，故障记录跟踪设备异常。

质量追溯模块通过批次消耗关系实体建立生产订单与采购订单明细之间的多对多关联，实现从成品批次正向追溯原材料来源、从原材料批次反向追溯流入成品的双向追溯能力。

系统管理模块提供用户、角色、权限三层访问控制体系，用户与角色多对多分配，角色与权限多对多授予。登录行为和操作日志分别记录认证审计与业务操作审计。

跨模块共享实体包括物料（被采购、库存、生产、质量追溯模块引用）、用户（被采购、库存、生产模块引用）、供应商（被采购模块引用）、生产订单（被库存、质量追溯模块引用）、采购订单明细（被质量追溯模块引用）和版本（被生产模块引用）。这些共享实体构成模块间的数据纽带，确保业务流程端到端贯通。

## 2.2 物料与BOM管理模块E-R图

# 3 逻辑设计
以下为数据表和数据库关系的设计。

## 3.1 表的设计
系统共设计35张数据表。

物料主表存储物料的基本信息，包括名称、类型、型号规格、计量单位、安全库存及默认供应商等。

物料分类表记录物料所属的分类名称。

物料库存表维护每种物料的可用数量、锁定数量及最后出入库日期。

供应商表存储供应商的名称、联系人和联系电话。

BOM版本表记录BOM的版本号、生效失效日期及变更原因。

BOM明细表存储父子物料之间的组成关系、单位用量和损耗率。

需求分析结果表保存基于BOM展开计算得出的物料净需求量。

采购订单表记录采购订单的供应商、状态、预计交货日期和总金额。

采购订单明细表存储订单中每项物料的采购数量、单价和已到货量。

逾期提醒表记录采购订单的逾期天数及处理情况。

收货记录表记录每次到货的物料、数量和日期。

库存预警事件表记录库存低于安全阈值时触发的预警事件及处理状态。

库存锁定记录表记录因生产订单锁定的物料数量及释放情况。

废弃物料检测结果表记录长期闲置物料的检测结果，包括闲置天数和处理状态。

完工入库单表记录生产完工后的入库数量、合格数量和成品批次号。

生产线类型表定义生产线的类型名称。

生产线表记录每条生产线的类型、启用日期和负责人。

产品产能配置表配置每种产品所需的生产线类型及单件生产时间。

生产日历表以日期和生产线为联合主键，记录每日的排产安排。

生产订单表存储生产订单的产品、计划数量、已完工数量及计划与实际起止日期。

外部订单表记录外部客户的产品预订信息，包括数量、期望交付日期和审核状态。

外部订单与生产订单关联表维护外部订单和生产订单之间的对应关系。

产能检测结果表记录某周期内生产线的计划产能与实际产能的差异及原因分类。

产能平衡记录表保存产能调整前后的排产方案及受影响的订单。

故障记录表记录生产线故障的类型、描述、发生与恢复时间及维修人员。

生产线状态表维护各生产线的当前运行状态、正在生产的订单和效率。

批次消耗关系表记录生产订单消耗了哪批采购物料及消耗数量。

系统用户表存储用户的工号、密码哈希、姓名、联系方式和账号状态。

系统角色表定义系统中的角色名称和描述。

系统权限表定义可控制的资源及操作类型。

用户角色关联表记录用户与角色的多对多对应关系。

角色权限关联表记录角色与权限的多对多对应关系。

登录日志表记录用户每次登录的时间、IP地址和登录结果。

操作日志表记录用户的操作行为，包括操作模块、类型及操作前后的数据快照。

报价表维护各供应商对不同物料的报价及有效期。
